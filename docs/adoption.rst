Adoption Guides
===============

Method selection, comparisons, and the examples gallery for v1.0.

Method chooser
--------------

See ``docs/method_chooser.md`` in the repository for a decision tree: visibility
vs recurrence vs causal vs similarity graphs, and when to use
``build_decision_package()``.

Comparisons
-----------

See ``docs/comparisons.md`` for ts2net vs NetworkX, tsfresh, matrix profile,
and PyG/DGL integration patterns.

API stability
-------------

See ``docs/API_STABILITY.md`` for stable, experimental, and deprecated tiers.
Programmatic lists live in ``ts2net.api_tiers``.

Examples gallery
----------------

See ``examples/GALLERY.md`` for a copy-paste index of scripts and notebooks.
Domain recipes live under ``examples/recipes/`` with matching ``.ipynb``
notebooks.

Migration
---------

Upgrading from v0.9? See ``MIGRATION.md`` at the repository root.
